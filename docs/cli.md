# CLI reference

```
ctx-lint [global options] <command> [options]
```

## Global options

| Option | |
|---|---|
| `--cwd <dir>` | Project root. Default: the nearest git root above the current directory |
| `--config <path>` | Config file. Default: `.context/config.json` in the project root |
| `--no-color` | Plain output (also when the `NO_COLOR` environment variable is set) |
| `--debug` | Debug logging and stack traces |
| `-v`, `--version` | Print the version |
| `-h`, `--help` | Help for `ctx-lint` or a command |

## `ctx-lint check [files...]`

Lint agent instruction files. With no files, every instruction file in the repo is discovered.
See [check.md](check.md).

| Option | |
|---|---|
| `--format <format>` | `stylish` (default), `compact`, `json`, `github`, `sarif` |
| `--fix` | Apply unambiguous fixes, then report what's left |
| `--max-warnings <n>` | Exit 1 when there are more than `n` warnings |
| `--quiet` | Report errors only |
| `--rule <id=severity>` | Override a rule: `error`, `warn` or `off` (repeatable) |
| `--no-deps` | Skip the `dependency-installed` check |
| `--list-files` | Print the files that would be linted, then exit |
| `--dump-refs` | Print every reference found, then exit (with `--debug`, ignored ones too) |

## `ctx-lint sync`

Compile `.context/rules` into each enabled agent's files. See [sync.md](sync.md).

| Option | |
|---|---|
| `--dry-run` | Print the planned changes as diffs, write nothing |
| `--check` | Write nothing; exit 1 if generated files are out of date |
| `--target <id>` | Only `claude`, `agents`, `cursor`, `copilot` or `windsurf` (repeatable) |
| `--force` | Overwrite files that weren't generated by `ctx-lint` |

## `ctx-lint audit`

Estimate token cost per agent and check the always-on budget. See [audit.md](audit.md).

| Option | |
|---|---|
| `--budget <tokens>` | Always-on budget for every agent (default: `audit.budget`) |
| `--tokenizer <name>` | `heuristic` (default), `o200k` or `cl100k` |
| `--format <format>` | `table` (default) or `json` |
| `--per-section` | List every section of the always-on files |
| `--warn-only` | Never exit non-zero for budget overruns |

## `ctx-lint init`

Create `.context/config.json` and a starter rule.

| Option | |
|---|---|
| `--import` | Convert existing `CLAUDE.md`, `AGENTS.md`, Cursor, Copilot and Windsurf files into source rules |
| `--split` | With `--import`: one rule per `##` section of a file |

## `ctx-lint explain [rule]`

Print what a rule checks, its default severity and how to fix its problems. Without a rule, list
every rule. Rule ids are matched with typo suggestions (`path-exist` → `path-exists`).

## Exit codes

| Code | Meaning |
|---|---|
| `0` | Success: no errors, budget met, generated files up to date |
| `1` | Lint errors (or too many warnings), budget exceeded, `sync --check` found stale files, or `sync` stopped on a conflict or invalid source rules |
| `2` | Usage error, invalid configuration, or an unexpected crash |
